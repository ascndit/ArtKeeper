# ArtKeeper

Настольное приложение для учёта музейных экспонатов.

## Стек

.NET 8, WPF, Entity Framework Core, SQL Server

## Разделы

- вход
- экспонаты
- выставки
- реставрация
- пользователи

Экраны собраны по схеме View и ViewModel, данные лежат в моделях EF Core.

## Запуск

Нужны .NET 8 SDK и SQL Server. Откройте `ArtKeeper.sln` и проверьте строку подключения в `ArtKeeperContext`.
